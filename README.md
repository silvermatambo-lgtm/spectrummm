# WebDevPro Master One-Page Website Template

Reusable Vite + React template for fast client demo websites.

## Fast workflow

1. Edit `src/config/site.ts`.
2. Replace the placeholder files in `public/images/` with the client's logo and photos.
3. Run `npm install`.
4. Run `npm run build`.
5. Deploy the generated `dist/` folder or connect the repository to Vercel, Netlify, or Cloudflare Pages.

The layout includes the animated hero slider/typewriter, About, Services, Why Us, Process, project gallery/lightbox, quote CTA, FAQ, contact/WhatsApp form, floating WhatsApp assistant, mobile footer navigation, back-to-top control, privacy/terms text, and WebDevPro footer credit.

See `TEMPLATE-GUIDE.md` for deployment details.
